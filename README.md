# Приложение «Интернет-магазин "Megano"»

## Описание проекта:
Онлайн-платформа для размещения и продажи товаров. Разработана в рамках итогового проекта, аналогично таким сервисам
как holodilnik.ru, citilink.ru, ozon.ru. Проект реализован на фреймворке Django, полностью переносим и легко 
разворачивается в любой среде.

## Структура сайта
Главная страница:

- Три избранные категории товаров.

- Каталог топ-товаров (popular products).

- Слайдер с ограниченным тиражом (Limited edition).

Каталог:

- Каталог товаров с возможностью фильтрации, сортировки и постраничной навигации.

- У каждого товара отображаются:
- Название, изображение товара, краткое описание.
- Цена товара.

- Количество отзывов.

- Кнопка «Купить».

Детальная страница товара:

- Отображается подробная информация о товаре, отзывы с возможностью подгрузить ещё и добавить новый отзыв.

Оформление заказа:

- Корзина: отображает все товары в корзине с элементами управления количеством и кнопкой удаления.

- Оформление заказа: пошаговое оформление заказа — ввод данных пользователя, выбор способа доставки и оплаты, подтверждение заказа.

- Фиктивная страница оплаты: введение номера карты или генерация случайного счёта.

Личный кабинет:

- Просмотр и редактирование профиля пользователя.

- История заказов с возможностью повторного оформления заказа.

Административный раздел:

- Управление пользователями, товарами, категориями и заказами через Django Admin.

- Возможность редактирования, добавления и удаления элементов с механизмом мягкого удаления.


### Установка:
1. Скачать репозиторий
2. Установить виртуальную среду __python -m venv <название>__
3. Установить зависимости: __pip install -r requirements.txt__
4. Прописать в __.env__ логин и пароль административной панели (согласно __.env.template__)
5. Создать миграции: __python manage.py makemigrations__
6. Применить миграции: __python manage.py migrate__
7. Запустить сервер: __python manage.py runserver__
8. Запустить команду импорта фикстур из папки проекта backend: __python manage.py loaddata fixtures/all_data.json__
